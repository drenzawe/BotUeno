# Discord Bot Ueno
A multi-purpose Discord bot built with Discord.Net (v1.0.1) and C#. Features an XP/leveling system with rank-based guild roles, point-based gambling games (Rock Paper Scissors & Coin Flip), moderation commands, meme/image posting, and music streaming capabilities. Uses MySQL for data persistence.

Features:

XP & Leveling system with automatic role progression (Peasant → Plebian → Commoner → Loyalist → Elite)

Points economy system

Gambling games: Rock Paper Scissors, Coin Flip

Moderation: Kick, Ban, Purge messages

Fun commands: Memes, Best Girl images

Music playback from YouTube URLs

User status tracking (Level, XP, Points, Role)

MySQL database integration

Tech Stack:

C# / .NET Framework 4.6.1

Discord.Net 1.0.1

MySQL / Entity Framework 6

FFmpeg & youtube-dl for audio streaming
